# auto_Install_honk
自动一键安装honk到docker中.

honk一键安装脚本带交互。自动识别网口、自动生成最小配置文件。如果有配置文件，放在脚本同一目录下。
修复docker容器中自连流量不放行问题。[源仓库安装文档]([https://example.com](https://github.com/daeuniverse/honk/blob/d3789f1bea3575866e3ee7342d87fac2bf422045/doc/zh/how-to-start.md))
自动加速github下载地址，解决国内无法访问导致拉取失败问题。

配置文件已经配置好，国内外无DNS泄露问题。
